# Журнал действий, лабораторная 3, вариант 9

Задание: файловый минифильтр, дискреционные права в XML, защита файла правил, IOCTL, нотификатор загрузки образов.

## Что делаю

Старое ТЗ уже дало минифильтр `FsFilterX`, программу `filetool` и тестовую подпись. Их не выбрасываю. Меняю правила и добавляю то, чего в старой работе не было.

Решения из `План.md`, которым следую:

- правила в `C:\DriverConfig\policy.xml`, старый `Config.txt` не удаляю и драйвер его больше не читает;
- файла нет в XML — доступ есть; файл есть, а процесса в его списке нет — отказ;
- `policy.xml` открывает только `fsctl.exe` и сам драйвер, когда перечитывает правила;
- перечитывание только по IOCTL, не на каждой операции;
- устройство `\\.\FsFilterX`, коды 0x800 / 0x801 / 0x802;
- журнал `C:\DriverConfig\image.log`, описатель открывается при включении нотификатора.

## Ход

1. `FsFilterX.c` написан заново, без неиспользуемых колбэков nullFilter. Рядом лежат `ioctl.h`, образец `config\policy.xml` и программа `fsctl`.
2. Сборка до прогона: драйвер x64 Debug `FsFilterX\FsFilterX\x64\Debug\FsFilterX.sys` (до подписи 22376 байт, 2026-10-30 16:18), `fsctl` x64 Release, `filetool` не менялся.
3. `install-filter.ps1` запускался от администратора три раза. Ниже — что показал каждый прогон. `C:\DriverConfig\Config.txt` не удалялся.

### Прогон 1, 16:22, код выхода 1

Подпись SHA256 прошла, `signtool verify /pa` прошёл, `fltmc load` прошёл. `FsFilterX` встал на высоте 370030.

Поведение доступа было верным, это видно по stdout в `install-result.txt` того прогона:

- `filetool r note.txt` напечатал `hello`, запись `hacked` получила `file openning failed`, файл остался `hello`;
- `report.txt` принял запись `written`, файл вне списка `free.txt` принял `free-ok`;
- копия `filetool`, названная `notepad.exe`, не смогла ни прочитать, ни записать `note.txt`;
- `fsctl set ... filetool.exe 1 1` разрешил запись `allowed-now`, следующий `set ... 1 0` снова запретил запись, в файле осталось `allowed-now`;
- `filetool` не открыл `policy.xml`, `fsctl show` его прочитал;
- `notify on` и `notify off` вернули код 0;
- выгрузка при включённом нотификаторе прошла, после новой загрузки `filetool` снова прочитал `allowed-now`.

Единственная красная проверка скрипта: «журнал не растёт». Длина была 1043, затем 1953. Это ошибка измерения, не драйвера. Длину сняли до команды `fsctl notify off`. Пока нотификатор ещё включён, сам `fsctl.exe` загружает DLL, и эти строки попадают в журнал.

Отдельно, уже без переустановки: `notify on`, чтение `note.txt` через `filetool`, `notify off`, пауза, длина 10506, ещё одно чтение, длина снова 10506. После выключения нотификатора файл не растёт, и в нём есть строки `process=filetool.exe`.

Вторая ошибка скрипта: `[IO.File]::ReadAllText` не открывает `image.log`, пока драйвер держит его на запись (`FILE_SHARE_READ` у драйвера, а у .NET нет `FILE_SHARE_WRITE`). Чтение с `FileShare.ReadWrite` файл открывает.

### Прогон 2, код выхода 1

Проверки журнала уже зелёные: `process=filetool.exe` найден, длина 2065 и после `notify off` снова 2065. Выгрузка с включённым нотификатором прошла.

Три проверки `hello` упали, потому что `note.txt` так и остался `allowed-now`. Скрипт копировал его, пока фильтр ещё был загружен. `powershell.exe` в правилах нет, поэтому перезапись защищённого файла не прошла, а `Copy-Item` при `$ErrorActionPreference = Continue` не остановил скрипт.

### Прогон 3, код выхода 0

Фильтр сначала выгружается, и только потом заново кладутся `policy.xml`, `note.txt` (`hello`), `report.txt` и `free.txt`. В журнале прогона: `note seeded: [hello]`.

Дальше всё зелёное, строка `FAILED 0` и `done`:

- чтение `hello`, запрет записи, файл не затёрт;
- запись в `report.txt` и в свободный `free.txt`;
- `notepad.exe` к `note.txt` не допущен;
- `fsctl set` меняет право на запись без перезагрузки, повторный `set` запрет возвращает;
- `policy.xml` скрыт от `filetool` и виден `fsctl show`;
- нотификатор пишет `process=filetool.exe`, после `notify off` длина 1955 и 1955;
- `fltmc unload` при включённом нотификаторе и следующая загрузка проходят, после загрузки `note.txt` читается.

Подпись: `Successfully signed` и `Successfully verified: C:\WINDOWS\System32\drivers\FsFilterX.sys`. Размер установленного sys — 21920 байт. В `fltmc filters` строка `FsFilterX`, 11 экземпляров, высота 370030. Служба после прогона осталась RUNNING. `C:\DriverConfig\Config.txt` на месте, `policy.xml` тоже.
